# DIECI - Configuración del Asistente y Estándares Visuales

Este proyecto cuenta con un conjunto de skills y reglas de diseño visual de alta calidad adaptadas de *vibe-coder-kit*.

---

## 🎨 Skills Disponibles para Diseño Visual

1. **`ui-ux-pro-max`** (`.agents/skills/ui-ux-pro-max/SKILL.md`):
   - Sistema integral de diseño UI/UX, búsqueda de paletas, tipografías, componentes, GSAP motion, landing pages y stacks específicos con scripts de búsqueda automatizados (`scripts/search.py`).
2. **`ui-ux-designer`** (`.agents/skills/ui-ux-designer/SKILL.md`):
   - Especializada en definición de sistemas de diseño, paletas de color HSL armónicas, tipografía moderna, jerarquía visual, espaciado con base de 4px y micro-animaciones fluidas.
3. **`frontend-visual-polish`** (`.agents/skills/frontend-visual-polish/SKILL.md`):
   - Especializada en maquetación con CSS Grid, Flexbox, variables CSS, glassmorphism sutil, animaciones a 60 FPS con aceleración de hardware, responsive design (mobile-first) y accesibilidad WCAG.


---

## 📐 Reglas Activas de Calidad (`.agents/rules/`)

- **`ui-design.md`**: Directrices obligatorias de estética moderna, contraste, tipografía y prevención de clichés visuales.
- **`code-hygiene.md`**: Estándares de limpieza de CSS, HTML semántico y rendimiento.

---

## 🚀 Flujo de Trabajo para Tareas Visuales

1. **Analizar la necesidad:** Identificar los objetivos del usuario y la jerarquía de la pantalla.
2. **Establecer tokens:** Definir o actualizar variables CSS (`:root`) para colores, espaciados y sombras.
3. **Maquetar y estilizar:** Construir componentes accesibles, responsivos y con micro-interacciones suaves.
4. **Validar:** Comprobar adaptabilidad en móviles, contraste y fluidez de animaciones.
